# Nest Display Player for Raspberry Pi

Turn any Raspberry Pi into a Nest Display digital signage screen.

## Download

Get the latest image from the **[Releases page](../../releases/latest)**.

- **Raspberry Pi Imager (recommended):** download `nest-display.img.xz`
- **balenaEtcher:** download `nest-display.img.zip` and extract it before flashing

Only the current version is offered here, so you always get the newest player.

## What you need

- Raspberry Pi 3, 4, 5 or Zero 2 W
- An SD card of 8GB or larger
- A screen with HDMI
- A Nest Display account

## Setup

1. Flash the image to your SD card with Raspberry Pi Imager (**Choose OS → Use custom**) or balenaEtcher
2. Insert the card into the Pi, connect it to your screen and power it on
3. On your phone, join the **"Nest Display Setup"** WiFi network and enter your WiFi details
4. The Pi restarts and shows a pairing code
5. In your Nest Display dashboard go to **Screens → Pair a Screen** and enter the code

Full flashing and troubleshooting steps are included in the notes of each release.
